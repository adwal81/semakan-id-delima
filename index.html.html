Panduan & Kod Google Apps Script

Struktur lajur Google Sheet mestilah:

BIL | NAMA MURID | KELAS | ID DELIMa | STATUS | KATA LALUAN

Kod Google Apps Script (Buka Google Sheet → Extensions → Apps Script):

function doGet() {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = sheet.getDataRange().getValues();
  var rows = [];
  for (var i = 1; i < data.length; i++) {
    rows.push({
      bil: data[i][0],
      nama: data[i][1],
      kelas: data[i][2],
      idDelima: data[i][3],
      status: data[i][4],
      kataLaluan: data[i][5] || '#Mba2030'
    });
  }
  return ContentService.createTextOutput(JSON.stringify(rows))
    .setMimeType(ContentService.MimeType.JSON);
}
